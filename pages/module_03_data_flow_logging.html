Data Flow & Diagnostic Logging

CSV Telemetry

Every Building Automation System (BAS) logs trend data — temperature readings, pressure values, equipment status — timestamped and stored for analysis. In Python, we do the exact same thing using the csv module and file I/O. In this module, you'll record every cycle of your AC simulation to a CSV file, then read it back for analysis.

🏢 3.1 — The BAS/BMS Trend Log Analogy

If you've ever worked with a Tridium Niagara, Honeywell, or Johnson Controls BAS, you've seen trend logs. They look something like this:

Timestamp Point Name Value Unit Status
2025-01-15 08:00:01RTU-01.SAT55.2°FNormal
2025-01-15 08:00:01RTU-01.RAT72.8°FNormal
2025-01-15 08:00:01RTU-01.DischPSI408PSINormal
2025-01-15 08:00:01RTU-01.SuctPSI68PSINormal
2025-01-15 08:05:01RTU-01.SAT54.9°FNormal

This is exactly what a CSV (Comma-Separated Values) file looks like — rows and columns of data, separated by commas. Python's built-in csv module makes it easy to create, write, and read these files.

📁 3.2 — File I/O: Reading and Writing Files

Before we get to CSV, let's understand the basics of opening and writing files in Python. The key concept is the context manager — the with statement: 

# ═══ Basic File Writing ═══

# The 'with' statement opens a file and GUARANTEES it gets closed
# Even if an error occurs, the file will be properly closed
# Think of it like a safety switch — it always resets

with open("sensor_log.txt", "w") as file:
    # "w" = write mode (creates new file or overwrites existing)
    file.write("HVAC Sensor Log\n")
    file.write("===============\n")
    file.write("Supply Air Temp: 55.2°F\n")
    file.write("Return Air Temp: 72.8°F\n")
    file.write("Status: Normal\n")

# When we exit the 'with' block, the file is automatically closed
# This is critical — unclosed files can lose data or lock resources
print("✅ Log file written successfully!")

Why with Matters — The Context Manager

Think of the with statement like a lockout/tagout procedure. When you open a panel to work on electrical, you lock it out so nobody else can energize it while you're inside. When you're done, you remove the lock. The with statement does this automatically for files:

  • Opens the file (like opening the panel)
  • Gives you access to read/write (like doing your work inside)
  • Automatically closes when you're done — even if an error occurs (like removing your lock)
# ═══ File Modes ═══
# "w"  — Write mode: creates new file, overwrites if exists
# "r"  — Read mode: reads existing file (error if doesn't exist)
# "a"  — Append mode: adds to end of file (creates if doesn't exist)

# Appending is like adding new trend data to an existing log
with open("sensor_log.txt", "a") as file:
    file.write("\n--- New Readings ---\n")
    file.write("Supply Air Temp: 54.8°F\n")
    file.write("Return Air Temp: 72.1°F\n")

# Reading the file back
with open("sensor_log.txt", "r") as file:
    contents = file.read()
    print(contents)

📊 3.3 — Writing CSV Files: Your Digital Trend Log

Now let's use Python's csv module to write structured data with proper headers and rows — exactly like a BAS exports trend data: 

import csv
from datetime import datetime

# ═══ Creating a CSV Trend Log ═══

# Define the headers (column names)
headers = [
    "timestamp",
    "cycle",
    "room_temp_f",
    "supply_air_f",
    "return_air_f",
    "discharge_psi",
    "suction_psi",
    "refrigerant_state",
    "system_status"
]

# Open the CSV file for writing
with open("hvac_trend_log.csv", "w", newline="") as csvfile:
    writer = csv.writer(csvfile)

    # Write the header row first
    writer.writerow(headers)

    # Write some sample data rows
    writer.writerow([
        datetime.now().isoformat(),
        1, 82.0, 55.2, 72.8, 412, 68, "gas", "COOLING"
    ])
    writer.writerow([
        datetime.now().isoformat(),
        2, 80.0, 54.9, 72.1, 408, 67, "gas", "COOLING"
    ])
    writer.writerow([
        datetime.now().isoformat(),
        3, 78.0, 55.0, 71.5, 410, 68, "gas", "COOLING"
    ])

print("✅ CSV trend log created: hvac_trend_log.csv")

Using DictWriter for Named Columns

csv.DictWriter lets you write rows as dictionaries — matching column names to values. This is cleaner and less error-prone than positional writing: 

import csv
from datetime import datetime

headers = [
    "timestamp", "cycle", "room_temp_f", "supply_air_f",
    "discharge_psi", "suction_psi", "system_status"
]

with open("hvac_trend_log.csv", "w", newline="") as csvfile:
    writer = csv.DictWriter(csvfile, fieldnames=headers)

    # Write header row
    writer.writeheader()

    # Write rows as dictionaries — much more readable!
    writer.writerow({
        "timestamp": datetime.now().isoformat(),
        "cycle": 1,
        "room_temp_f": 82.0,
        "supply_air_f": 55.2,
        "discharge_psi": 412,
        "suction_psi": 68,
        "system_status": "COOLING_STAGE_1"
    })

    writer.writerow({
        "timestamp": datetime.now().isoformat(),
        "cycle": 2,
        "room_temp_f": 80.0,
        "supply_air_f": 54.9,
        "discharge_psi": 408,
        "suction_psi": 67,
        "system_status": "COOLING_STAGE_1"
    })

🔄 3.4 — Complete AC Simulation with CSV Logging

Now let's combine our Module 2 AC functions with CSV logging. Every cycle writes a row to the trend log — just like a real BMS: 

import csv
from datetime import datetime, timedelta

def evaporator(refrigerant, room_temp):
    """Evaporator absorbs heat from room air."""
    new_ref = {
        "temp": refrigerant["temp"] + 15.0,
        "pressure": refrigerant["pressure"],
        "state": "gas"
    }
    new_room = room_temp - 2.0
    return new_ref, new_room

def compressor(refrigerant):
    """Compressor squeezes gas, raising temp and pressure."""
    return {
        "temp": refrigerant["temp"] + 80.0,
        "pressure": int(refrigerant["pressure"] * 6),
        "state": "gas"
    }

def condenser(refrigerant, outdoor_temp):
    """Condenser rejects heat outdoors."""
    return {
        "temp": outdoor_temp + 10.0,
        "pressure": refrigerant["pressure"],
        "state": "liquid"
    }

def expansion_valve(refrigerant):
    """Expansion valve drops pressure and temperature."""
    return {
        "temp": 40.0,
        "pressure": int(refrigerant["pressure"] / 6),
        "state": "liquid"
    }

# ═══ SIMULATION WITH CSV LOGGING ═══
def run_simulation_with_logging(filename="hvac_telemetry.csv"):
    """Run AC simulation and log every cycle to CSV."""

    room_temp = 85.0
    outdoor_temp = 95.0
    setpoint = 72.0
    refrigerant = {"temp": 40.0, "pressure": 68, "state": "liquid"}

    headers = [
        "timestamp", "cycle", "room_temp", "outdoor_temp",
        "ref_temp", "ref_pressure", "ref_state",
        "component", "system_status"
    ]

    sim_time = datetime(2025, 7, 15, 8, 0, 0)  # Simulated start time

    with open(filename, "w", newline="") as csvfile:
        writer = csv.DictWriter(csvfile, fieldnames=headers)
        writer.writeheader()

        cycle = 0
        while room_temp > setpoint and cycle < 15:
            cycle += 1
            sim_time += timedelta(minutes=5)  # 5-minute intervals

            # Run all four components and log after each
            refrigerant, room_temp = evaporator(refrigerant, room_temp)
            writer.writerow({
                "timestamp": sim_time.isoformat(),
                "cycle": cycle, "room_temp": f"{room_temp:.1f}",
                "outdoor_temp": outdoor_temp,
                "ref_temp": f"{refrigerant['temp']:.1f}",
                "ref_pressure": refrigerant["pressure"],
                "ref_state": refrigerant["state"],
                "component": "evaporator",
                "system_status": "COOLING"
            })

            refrigerant = compressor(refrigerant)
            writer.writerow({
                "timestamp": sim_time.isoformat(),
                "cycle": cycle, "room_temp": f"{room_temp:.1f}",
                "outdoor_temp": outdoor_temp,
                "ref_temp": f"{refrigerant['temp']:.1f}",
                "ref_pressure": refrigerant["pressure"],
                "ref_state": refrigerant["state"],
                "component": "compressor",
                "system_status": "COOLING"
            })

            refrigerant = condenser(refrigerant, outdoor_temp)
            refrigerant = expansion_valve(refrigerant)

            print(f"  Cycle {cycle:>2}: Room = {room_temp:.1f}°F")

        status = "SATISFIED" if room_temp <= setpoint else "MAX_CYCLES"
        print(f"\n✅ Simulation complete. {cycle} cycles logged to {filename}")
        print(f"   Final room temp: {room_temp:.1f}°F | Status: {status}")

run_simulation_with_logging()

📖 3.5 — Reading CSV Back: Analyzing Your Trend Data

Now that we have logged data, let's read it back — just like pulling a trend report from your BAS. Python's csv.DictReader reads each row as a dictionary: 

import csv

# First, create sample trend data (normally written by previous block)
sample_data = [
    {"timestamp": "10:00:00", "cycle": 1, "component": "evaporator", "room_temp": "85.0", "ref_temp": "55.0"},
    {"timestamp": "10:01:00", "cycle": 2, "component": "compressor", "room_temp": "83.0", "ref_temp": "135.0"},
    {"timestamp": "10:02:00", "cycle": 3, "component": "condenser", "room_temp": "81.0", "ref_temp": "105.0"},
    {"timestamp": "10:03:00", "cycle": 4, "component": "evaporator", "room_temp": "79.0", "ref_temp": "55.0"},
    {"timestamp": "10:04:00", "cycle": 5, "component": "compressor", "room_temp": "77.0", "ref_temp": "135.0"},
]
with open("hvac_telemetry.csv", "w") as f:
    writer = csv.DictWriter(f, fieldnames=sample_data[0].keys())
    writer.writeheader()
    writer.writerows(sample_data)

# ═══ Reading the Trend Log ═══
def analyze_trend_log(filename="hvac_telemetry.csv"):
    """Read CSV trend data and produce a summary report."""

    rows = []
    with open(filename, "r") as csvfile:
        reader = csv.DictReader(csvfile)
        for row in reader:
            rows.append(row)

    print(f"📊 TREND LOG ANALYSIS")
    print(f"   File: {filename}")
    print(f"   Total records: {len(rows)}")
    print(f"   Time range: {rows[0]['timestamp']} → {rows[-1]['timestamp']}")
    print()

    # Extract room temperatures (convert from string to float)
    room_temps = [float(row["room_temp"]) for row in rows]

    print(f"   Room Temperature Summary:")
    print(f"     Start:   {room_temps[0]:.1f}°F")
    print(f"     End:     {room_temps[-1]:.1f}°F")
    print(f"     Max:     {max(room_temps):.1f}°F")
    print(f"     Min:     {min(room_temps):.1f}°F")
    print(f"     Average: {sum(room_temps)/len(room_temps):.1f}°F")
    print()

    # Count records by component
    components = {}
    for row in rows:
        comp = row["component"]
        components[comp] = components.get(comp, 0) + 1

    print(f"   Records by Component:")
    for comp, count in components.items():
        print(f"     {comp}: {count} records")

analyze_trend_log()

List Comprehensions — Quick Data Extraction

That line [float(row["room_temp"]) for row in rows] is called a list comprehension. It's a compact way to build a list by transforming each item. Think of it as "for every row in my data, grab the room_temp and convert it to a number": 

# Sample data (normally loaded from CSV — see blocks above)
rows = [
    {"room_temp": "82.0", "timestamp": "10:00"},
    {"room_temp": "80.5", "timestamp": "10:05"},
    {"room_temp": "79.0", "timestamp": "10:10"},
    {"room_temp": "77.2", "timestamp": "10:15"},
    {"room_temp": "75.8", "timestamp": "10:20"},
]

# Long way (standard loop)
room_temps = []
for row in rows:
    temp = float(row["room_temp"])
    room_temps.append(temp)
print(f"Temps (loop):          {room_temps}")

# Short way (list comprehension) — same result!
room_temps = [float(row["room_temp"]) for row in rows]
print(f"Temps (comprehension): {room_temps}")

# You can even filter! Only get temps above 80°F:
high_temps = [float(row["room_temp"]) for row in rows
              if float(row["room_temp"]) > 80.0]
print(f"High temps (>80°F):    {high_temps}")

🎯 Module 3 Key Takeaways

  • File I/O lets you persist data beyond program execution — your digital trend log.
  • The with statement (context manager) guarantees files get closed properly — like lockout/tagout for data.
  • csv.DictWriter writes structured data with column headers.
  • csv.DictReader reads CSV files as dictionaries — easy column access by name.
  • List comprehensions extract and transform data from lists quickly.
  • CSV trend logging is exactly how BAS/BMS systems store historical data for analysis.
