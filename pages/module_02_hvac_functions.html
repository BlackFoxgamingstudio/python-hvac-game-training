HVAC as Functions

Mapping Hardware to Software

An air conditioning system has four main components: the evaporator, compressor, condenser, and expansion valve. Each one takes refrigerant in one state and transforms it into another. In Python, that's exactly what a function does — takes input, does work, and produces output. Let's build each component as code.

🔄 2.1 — The Refrigeration Cycle: A System of Transformations

Before we write code, let's review the cycle you already know. Refrigerant flows through four components in a loop, changing temperature, pressure, and state (liquid vs. gas) at each stage:

❄️

1. Evaporator

Physics: Low-pressure liquid refrigerant absorbs heat from indoor air, boiling into a low-pressure gas. Indoor air gets cooler.

Analogy: Sweat evaporating off your skin — it absorbs body heat and cools you down.

→
🔧

2. Compressor

Physics: Squeezes the low-pressure gas into high-pressure gas. Temperature spikes dramatically (PV=nRT — compress gas, temp rises).

Analogy: A bicycle pump getting hot when you pump air — you're compressing gas.

→
🌡️

3. Condenser

Physics: Hot high-pressure gas rejects heat to outdoor air, condensing into a high-pressure liquid. The outdoor unit's fan blows this heat away.

Analogy: A car radiator — hot fluid flows through, air blows over it, heat leaves.

→
💧

4. Expansion Valve

Physics: High-pressure liquid passes through a tiny orifice, pressure drops dramatically. Refrigerant becomes a cold low-pressure mix, ready to absorb heat again.

Analogy: Spray can getting cold when you spray — pressure drops, temperature drops.

Now let's translate each component into a Python function. Each function will receive a dictionary containing the refrigerant's current state and return a new dictionary with the transformed state.

🧱 2.2 — What Is a Function?

A function is a reusable block of code that performs a specific task. It has three parts:

  1. Parameters (inputs) — What goes in. Like refrigerant entering a component.
  2. Body (the work) — What happens inside. The transformation.
  3. Return value (output) — What comes out. The transformed refrigerant.
# Basic function syntax
def function_name(parameter1, parameter2):
    """Docstring: explains what the function does."""
    # Do some work
    result = parameter1 + parameter2
    return result  # Send the result back

# Calling (using) the function
answer = function_name(10, 20)
print(answer)  # 30

Dictionaries: Bundling Related Data

We need to pass multiple values together — temperature, pressure, and state. A Python dictionary is perfect for this. It stores key-value pairs, like a label and its reading: 

# A dictionary holds related data together
refrigerant = {
    "temp": 40.0,       # Temperature in °F
    "pressure": 68,     # Pressure in PSI
    "state": "liquid"   # Physical state
}

# Access values by key
print(refrigerant["temp"])      # 40.0
print(refrigerant["state"])     # "liquid"

# Update a value
refrigerant["temp"] = 45.0
print(refrigerant["temp"])      # 45.0

❄️ 2.3 — Function 1: Evaporator

The evaporator absorbs heat from indoor air. Low-pressure liquid refrigerant enters, absorbs heat, and exits as low-pressure gas. The indoor air temperature drops. 

def evaporator(refrigerant, room_temp):
    """
    Simulate the evaporator coil.

    Physics: Low-pressure liquid refrigerant absorbs heat from indoor air,
    boiling into a gas. The room air cools down.

    Args:
        refrigerant: dict with 'temp', 'pressure', 'state'
        room_temp: current room temperature in °F

    Returns:
        tuple: (updated refrigerant dict, new room temperature)
    """
    print("  ❄️ EVAPORATOR:")
    print(f"     IN  → Temp: {refrigerant['temp']:.1f}°F | "
          f"Pressure: {refrigerant['pressure']} PSI | "
          f"State: {refrigerant['state']}")

    # Refrigerant absorbs heat from room air
    # It warms up and changes from liquid to gas
    heat_absorbed = 15.0  # BTU equivalent in degrees

    new_refrigerant = {
        "temp": refrigerant["temp"] + heat_absorbed,
        "pressure": refrigerant["pressure"],  # Pressure stays the same
        "state": "gas"  # Liquid boils into gas
    }

    # Room air loses the heat that refrigerant absorbed
    new_room_temp = room_temp - 2.0  # Room cools by ~2°F per cycle

    print(f"     OUT ← Temp: {new_refrigerant['temp']:.1f}°F | "
          f"Pressure: {new_refrigerant['pressure']} PSI | "
          f"State: {new_refrigerant['state']}")
    print(f"     Room temp: {room_temp:.1f}°F → {new_room_temp:.1f}°F")

    return new_refrigerant, new_room_temp

🔧 2.4 — Function 2: Compressor

The compressor is the heart of the system. It squeezes low-pressure gas into high-pressure gas. When you compress gas, its temperature rises dramatically — this is basic thermodynamics (PV = nRT). The compressor is what makes it possible to reject heat outdoors even when it's hot outside. 

def compressor(refrigerant):
    """
    Simulate the compressor.

    Physics: Mechanically compresses low-pressure gas into high-pressure gas.
    Temperature spikes due to compression (Gay-Lussac's Law: P/T = constant
    for fixed volume → increase P, T increases proportionally).

    Args:
        refrigerant: dict with 'temp', 'pressure', 'state'

    Returns:
        dict: updated refrigerant state
    """
    print("  🔧 COMPRESSOR:")
    print(f"     IN  → Temp: {refrigerant['temp']:.1f}°F | "
          f"Pressure: {refrigerant['pressure']} PSI | "
          f"State: {refrigerant['state']}")

    # Compression raises both pressure and temperature dramatically
    compression_ratio = 6.0  # Typical for R-410A systems

    new_refrigerant = {
        "temp": refrigerant["temp"] + 80.0,  # Huge temp spike from compression
        "pressure": int(refrigerant["pressure"] * compression_ratio),
        "state": "gas"  # Still a gas, just much hotter and denser
    }

    print(f"     OUT ← Temp: {new_refrigerant['temp']:.1f}°F | "
          f"Pressure: {new_refrigerant['pressure']} PSI | "
          f"State: {new_refrigerant['state']}")

    return new_refrigerant

🌡️ 2.5 — Function 3: Condenser

The condenser is the outdoor coil. Hot, high-pressure gas from the compressor flows through it while the condenser fan blows outdoor air across the coils. The refrigerant rejects its heat to the outdoors and condenses from gas back to liquid. 

def condenser(refrigerant, outdoor_temp):
    """
    Simulate the condenser coil.

    Physics: Hot high-pressure gas flows through outdoor coils.
    Condenser fan blows outdoor air across coils, removing heat.
    Refrigerant cools and condenses from gas to liquid.

    The condenser can only cool the refrigerant down NEAR the outdoor
    temp — it can't go below it (heat flows hot → cold).

    Args:
        refrigerant: dict with 'temp', 'pressure', 'state'
        outdoor_temp: current outdoor temperature in °F

    Returns:
        dict: updated refrigerant state
    """
    print("  🌡️ CONDENSER:")
    print(f"     IN  → Temp: {refrigerant['temp']:.1f}°F | "
          f"Pressure: {refrigerant['pressure']} PSI | "
          f"State: {refrigerant['state']}")

    # Refrigerant rejects heat to outdoor air
    # It can cool down to slightly above outdoor temp (approach temperature)
    approach_temp = 10.0  # Degrees above outdoor temp

    new_refrigerant = {
        "temp": outdoor_temp + approach_temp,
        "pressure": refrigerant["pressure"],  # Pressure stays high
        "state": "liquid"  # Gas condenses to liquid
    }

    heat_rejected = refrigerant["temp"] - new_refrigerant["temp"]

    print(f"     OUT ← Temp: {new_refrigerant['temp']:.1f}°F | "
          f"Pressure: {new_refrigerant['pressure']} PSI | "
          f"State: {new_refrigerant['state']}")
    print(f"     Heat rejected: {heat_rejected:.1f}°F to outdoor air ({outdoor_temp}°F)")

    return new_refrigerant

💧 2.6 — Function 4: Expansion Valve

The expansion valve (or TXV/metering device) is a restriction point. High-pressure liquid is forced through a tiny opening. Pressure drops instantly, and the refrigerant becomes a cold, low-pressure mix — ready to absorb heat in the evaporator again. 

def expansion_valve(refrigerant):
    """
    Simulate the expansion valve (TXV / metering device).

    Physics: High-pressure liquid passes through a small orifice.
    Pressure drops dramatically (Bernoulli's principle).
    Temperature drops with pressure (Joule-Thomson effect).
    Refrigerant becomes cold, low-pressure liquid/gas mix.

    Args:
        refrigerant: dict with 'temp', 'pressure', 'state'

    Returns:
        dict: updated refrigerant state
    """
    print("  💧 EXPANSION VALVE:")
    print(f"     IN  → Temp: {refrigerant['temp']:.1f}°F | "
          f"Pressure: {refrigerant['pressure']} PSI | "
          f"State: {refrigerant['state']}")

    # Pressure drops through the orifice → temperature drops too
    expansion_ratio = 6.0  # Inverse of compression ratio

    new_refrigerant = {
        "temp": 40.0,  # Drops to evaporator temperature (~40°F for R-410A)
        "pressure": int(refrigerant["pressure"] / expansion_ratio),
        "state": "liquid"  # Cold liquid, ready for evaporator
    }

    print(f"     OUT ← Temp: {new_refrigerant['temp']:.1f}°F | "
          f"Pressure: {new_refrigerant['pressure']} PSI | "
          f"State: {new_refrigerant['state']}")

    return new_refrigerant

🔄 2.7 — Running the Complete AC Cycle

Now we chain all four functions together in a loop — just like the real refrigeration cycle. The output of each function feeds into the next: 

# ═══ COMPLETE REFRIGERATION CYCLE SIMULATION ═══
# (includes all 4 HVAC functions for standalone execution)

def evaporator(refrigerant, room_temp):
    """Evaporator: absorbs heat from room, refrigerant boils to gas."""
    heat_absorbed = 15.0
    new_ref = {"temp": refrigerant["temp"] + heat_absorbed,
               "pressure": refrigerant["pressure"], "state": "gas"}
    new_room = room_temp - 2.0
    print(f"  ❄️ EVAPORATOR:  {refrigerant['temp']:.0f}°F liquid → {new_ref['temp']:.0f}°F gas | Room: {room_temp:.1f}→{new_room:.1f}°F")
    return new_ref, new_room

def compressor(refrigerant):
    """Compressor: squeezes low-pressure gas to high-pressure gas."""
    new_ref = {"temp": refrigerant["temp"] + 80.0,
               "pressure": int(refrigerant["pressure"] * 6), "state": "gas"}
    print(f"  🔧 COMPRESSOR:  {refrigerant['pressure']} PSI → {new_ref['pressure']} PSI | Temp spike to {new_ref['temp']:.0f}°F")
    return new_ref

def condenser(refrigerant, outdoor_temp):
    """Condenser: rejects heat outdoors, gas condenses to liquid."""
    new_ref = {"temp": outdoor_temp + 10.0,
               "pressure": refrigerant["pressure"], "state": "liquid"}
    print(f"  🌡️ CONDENSER:   {refrigerant['temp']:.0f}°F → {new_ref['temp']:.0f}°F | Heat rejected to {outdoor_temp}°F outdoor air")
    return new_ref

def expansion_valve(refrigerant):
    """Expansion valve: drops pressure, refrigerant becomes cold liquid."""
    new_ref = {"temp": 40.0,
               "pressure": int(refrigerant["pressure"] / 6), "state": "liquid"}
    print(f"  💧 EXPANSION:   {refrigerant['pressure']} PSI → {new_ref['pressure']} PSI | Temp drops to {new_ref['temp']:.0f}°F")
    return new_ref

def run_ac_cycle(num_cycles=5, room_temp=85.0, outdoor_temp=95.0):
    """
    Run the full AC refrigeration cycle for a given number of cycles.

    Args:
        num_cycles: how many complete cycles to simulate
        room_temp: starting indoor temperature in °F
        outdoor_temp: outdoor temperature in °F
    """
    # Initial refrigerant state (cold liquid in the evaporator)
    refrigerant = {
        "temp": 40.0,
        "pressure": 68,
        "state": "liquid"
    }

    setpoint = 72.0

    print(f"╔══════════════════════════════════════════════╗")
    print(f"║     AC CYCLE SIMULATION                     ║")
    print(f"║     Room: {room_temp}°F → Target: {setpoint}°F          ║")
    print(f"║     Outdoor: {outdoor_temp}°F                        ║")
    print(f"╚══════════════════════════════════════════════╝")
    print()

    for cycle in range(1, num_cycles + 1):
        print(f"{'='*50}")
        print(f"  CYCLE {cycle}")
        print(f"{'='*50}")

        # Step 1: Evaporator absorbs heat from room
        refrigerant, room_temp = evaporator(refrigerant, room_temp)

        # Step 2: Compressor squeezes the gas
        refrigerant = compressor(refrigerant)

        # Step 3: Condenser rejects heat outdoors
        refrigerant = condenser(refrigerant, outdoor_temp)

        # Step 4: Expansion valve drops pressure
        refrigerant = expansion_valve(refrigerant)

        print(f"\n  📊 After cycle {cycle}: Room = {room_temp:.1f}°F")

        if room_temp <= setpoint:
            print(f"\n  ✅ SETPOINT REACHED! Room is at {room_temp:.1f}°F")
            break

        print()

    print(f"\n{'='*50}")
    print(f"  SIMULATION COMPLETE")
    print(f"  Final room temp: {room_temp:.1f}°F")
    print(f"{'='*50}")

# Run it!
run_ac_cycle(num_cycles=10, room_temp=82.0, outdoor_temp=95.0)

🎯 Module 2 Key Takeaways

  • Functions encapsulate a single unit of work — just like an AC component.
  • Parameters are the inputs to a function — like refrigerant entering a component.
  • Return values are the outputs — the transformed refrigerant state.
  • Dictionaries bundle related data together with labeled keys.
  • Function chaining = piping output to input = the refrigeration cycle.
  • Each function has a clear single responsibility — one component, one job.
