📖 6.1 — Reading CSV Trend Logs for Analysis

In Module 3, we wrote CSV files. Now we read them back and process the data programmatically. Let's start by creating a sample log with some embedded faults that we'll detect:

from datetime import datetime, timedelta

    print(f"✅ Fault log generated: {filename} ({len(data)} records)")
    return filename

🔍 6.2 — Anomaly Detection: Finding Faults in Data

Now let's write a diagnostic engine that reads the CSV and checks every row against known fault thresholds. An experienced tech would check the same things: 

import csv

# Create sample fault data (normally generated by Block 1 above)
fault_headers = ["timestamp","cycle","room_temp","supply_air_temp","return_air_temp",

    ["2025-07-15T08:25",8,75.5,57.2,73.1,498,66,9.0,5.0,15.9,"ALARM"],
    ["2025-07-15T08:30",9,76.0,48.0,73.5,500,72,2.0,5.5,25.5,"ALARM"],
    ["2025-07-15T08:35",10,76.8,46.5,74.0,505,74,1.5,4.8,27.5,"CRITICAL"],

with open("fault_telemetry.csv", "w") as f:
    writer = csv.writer(f)
    writer.writerow(fault_headers)
    for row in fault_rows:
        writer.writerow(row)

class HVACDiagnosticEngine:
    """
    Automated HVAC fault detection engine.

    Reads trend data and checks each reading against known fault
    thresholds — just like an experienced tech scanning a trend log.
    """

    # Normal operating ranges (these are your "acceptable limits")
    THRESHOLDS = {
        "discharge_psi": {"min": 380, "max": 430, "name": "Discharge Pressure"},
        "suction_psi": {"min": 60, "max": 75, "name": "Suction Pressure"},
        "superheat": {"min": 5.0, "max": 15.0, "name": "Superheat"},
        "subcooling": {"min": 8.0, "max": 15.0, "name": "Subcooling"},
        "supply_air_temp": {"min": 48.0, "max": 60.0, "name": "Supply Air Temp"},
        "delta_t": {"min": 14.0, "max": 22.0, "name": "Delta-T"},
    }

    def __init__(self):
        self.faults = []
        self.readings = []

    def load_log(self, filename):
        """Load CSV trend data into memory."""
        self.readings = []
        with open(filename, "r") as csvfile:
            reader = csv.DictReader(csvfile)
            for row in reader:
                self.readings.append(row)
        print(f"📊 Loaded {len(self.readings)} records from {filename}")

    def check_threshold(self, value, param_name, cycle, timestamp):
        """Check if a value is outside its normal range."""
        if param_name not in self.THRESHOLDS:
            return

        threshold = self.THRESHOLDS[param_name]
        value = float(value)

        if value < threshold["min"]:
            severity = "CRITICAL" if value < threshold["min"] * 0.8 else "WARNING"
            self.faults.append({
                "cycle": cycle,
                "timestamp": timestamp,
                "parameter": threshold["name"],
                "value": value,
                "expected_range": f"{threshold['min']}-{threshold['max']}",
                "deviation": f"{threshold['min'] - value:.1f} below minimum",
                "severity": severity
            })
        elif value > threshold["max"]:
            severity = "CRITICAL" if value > threshold["max"] * 1.2 else "WARNING"
            self.faults.append({
                "cycle": cycle,
                "timestamp": timestamp,
                "parameter": threshold["name"],
                "value": value,
                "expected_range": f"{threshold['min']}-{threshold['max']}",
                "deviation": f"{value - threshold['max']:.1f} above maximum",
                "severity": severity
            })

    def run_diagnostics(self):
        """
        Scan all readings and detect faults.
        This is the automated equivalent of a tech reviewing trend data.
        """
        self.faults = []

        for row in self.readings:
            cycle = row["cycle"]
            timestamp = row["timestamp"]

            # Check each parameter against thresholds
            for param in self.THRESHOLDS:
                if param in row:
                    self.check_threshold(row[param], param, cycle, timestamp)

        print(f"\n🔍 DIAGNOSTIC SCAN COMPLETE")
        print(f"   Records scanned: {len(self.readings)}")
        print(f"   Faults detected: {len(self.faults)}")

        return self.faults

    def generate_fault_report(self):
        """Generate a formatted fault report."""
        if not self.faults:
            print("✅ No faults detected — system operating normally.")
            return ""

        report_lines = []
        report_lines.append("=" * 60)
        report_lines.append("  HVAC FAULT REPORT")
        report_lines.append("=" * 60)

        # Group faults by severity
        for severity in ["CRITICAL", "WARNING"]:
            severity_faults = [f for f in self.faults if f["severity"] == severity]
            if severity_faults:
                icon = "🚨" if severity == "CRITICAL" else "⚠️"
                report_lines.append(f"\n{icon} {severity} ({len(severity_faults)} faults):")
                report_lines.append("-" * 50)
                for fault in severity_faults:
                    report_lines.append(
                        f"  Cycle {fault['cycle']:>2} | {fault['parameter']:<20} | "
                        f"Value: {fault['value']:>7.1f} | "
                        f"Range: {fault['expected_range']}"
                    )

        report_lines.append("\n" + "=" * 60)
        report = "\n".join(report_lines)
        print(report)
        return report

🧠 6.3 — AI-Powered Troubleshooting with Gemini

Now the powerful part: feed the fault report to Gemini and let AI do what an expert tech would do — analyze the pattern of faults, identify root causes, and recommend corrective actions: 

import google.generativeai as genai
import os

class AITroubleshooter:
    """
    AI-powered HVAC troubleshooting assistant.

    Takes fault reports from the DiagnosticEngine and uses Gemini
    to analyze patterns, identify root causes, and recommend fixes.
    """

    def __init__(self):
        api_key = os.environ.get("GEMINI_API_KEY")
        if not api_key:
            raise ValueError("GEMINI_API_KEY not set!")

        genai.configure(api_key=api_key)
        self.model = genai.GenerativeModel("gemini-pro")

    def analyze_faults(self, fault_report, readings_summary):
        """
        Send fault data to Gemini for expert analysis.

        Args:
            fault_report: formatted string from DiagnosticEngine
            readings_summary: dict with min/max/avg of key parameters
        """
        prompt = f"""You are a senior HVAC diagnostic engineer with 20 years
of experience in commercial refrigeration and air conditioning systems.

A Building Automation System has flagged the following faults from
trend log data. Analyze the fault pattern and provide:

1. ROOT CAUSE ANALYSIS — What is most likely causing these faults?
2. FAULT PROGRESSION — How did the problem develop over time?
3. IMMEDIATE ACTIONS — What should the technician check first?
4. CORRECTIVE REPAIRS — What repairs are needed?
5. PREVENTIVE MEASURES — How to prevent this in the future?

FAULT REPORT:
{fault_report}

DATA SUMMARY:
- Supply Air Temp range: {readings_summary['sat_min']:.1f}°F to {readings_summary['sat_max']:.1f}°F
- Discharge Pressure range: {readings_summary['disch_min']} to {readings_summary['disch_max']} PSI
- Suction Pressure range: {readings_summary['suct_min']} to {readings_summary['suct_max']} PSI
- Superheat range: {readings_summary['sh_min']:.1f}°F to {readings_summary['sh_max']:.1f}°F

Provide your analysis in a clear, actionable format that a field
technician can follow. Use industry-standard HVAC terminology."""

        try:
            response = self.model.generate_content(prompt)
            return response.text
        except Exception as e:
            return f"❌ Analysis error: {e}"


# ═══ Run AI Analysis ═══
def run_full_diagnostic_pipeline(log_file="fault_telemetry.csv"):
    """Complete pipeline: Load → Detect → Analyze with AI."""

    # Step 1: Load and scan
    engine = HVACDiagnosticEngine()
    engine.load_log(log_file)
    faults = engine.run_diagnostics()
    fault_report = engine.generate_fault_report()

    # Step 2: Build readings summary
    sat_values = [float(r["supply_air_temp"]) for r in engine.readings]
    disch_values = [int(r["discharge_psi"]) for r in engine.readings]
    suct_values = [int(r["suction_psi"]) for r in engine.readings]
    sh_values = [float(r["superheat"]) for r in engine.readings]

    summary = {
        "sat_min": min(sat_values), "sat_max": max(sat_values),
        "disch_min": min(disch_values), "disch_max": max(disch_values),
        "suct_min": min(suct_values), "suct_max": max(suct_values),
        "sh_min": min(sh_values), "sh_max": max(sh_values),
    }

    # Step 3: AI analysis
    if faults:
        print("\n🧠 Sending fault data to AI for analysis...")
        troubleshooter = AITroubleshooter()
        analysis = troubleshooter.analyze_faults(fault_report, summary)
        print("\n" + "=" * 60)
        print("  AI DIAGNOSTIC ANALYSIS")
        print("=" * 60)
        print(analysis)
    else:
        print("✅ No faults found — system operating normally.")

import os
import time

def display_dashboard(readings, current_index, faults):

    Display a real-time terminal dashboard for HVAC monitoring.
    Clears the screen and redraws each cycle.

    os.system('clear' if os.name == 'posix' else 'cls')

    row = readings[current_index]
    cycle = row["cycle"]
    status = row["system_status"]

    status_icons = {
        "NORMAL": "🟢",
        "WARNING": "🟡",
        "ALARM": "🟠",

        "RECOVERY": "🔵"

    icon = status_icons.get(status, "⚪")

📋 6.5 — Common HVAC Fault Patterns

Here's a reference table of common faults, their symptoms in trend data, and likely root causes. Your diagnostic engine checks for these:

Fault Symptoms in Data Likely Root Cause
Dirty Condenser Coil High discharge pressure, low subcooling, rising room temp Restricted airflow across condenser coils — needs cleaning
Low Refrigerant Charge Low suction pressure, high superheat, low subcooling Refrigerant leak — find leak, repair, recharge
Frozen Evaporator Coil Supply air temp drops below 40°F, low suction pressure Airflow restriction (dirty filter), low charge, or TXV issue
Overcharged System High discharge pressure, high subcooling, liquid slugging risk Too much refrigerant — recover excess
Compressor Failure Equal suction and discharge pressure, no cooling Compressor not running or has lost compression
TXV Stuck Open Very low superheat (<3°F), flooding risk Expansion valve not metering properly — replace TXV

🎯 Module 6 Key Takeaways

  • Reading CSV data back is the foundation of all analytics — your BAS trend log analysis.
  • Threshold-based fault detection checks each reading against known good ranges.
  • Pattern analysis reveals how faults develop over time — not just individual readings.
  • AI troubleshooting combines data context with expert knowledge for intelligent diagnosis.
  • The diagnostic pipeline (load → detect → analyze → display) mirrors real BMS analytics platforms.
  • A terminal dashboard provides real-time visibility — your mini BAS display.
